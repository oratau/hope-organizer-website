# Email Assets

Folder ini berisi semua asset yang digunakan untuk desain email OTP.

## File yang Diperlukan:

### 1. Logo
- **logo.png** - Logo HOPE untuk header email (logo putih dengan "THE ORGANIZER")

### 2. Pattern/Background
- **pattern.png** - Pattern background untuk email (pattern HOPE yang transparan)

### 3. Icon (opsional jika menggunakan custom icon)
- **icon-email.png** - Icon email
- **icon-instagram.png** - Icon Instagram
- **icon-phone.png** - Icon telepon
- **icon-location.png** - Icon lokasi

## Catatan:
- Semua file akan digunakan dalam template email OTP
- Pastikan file logo dan pattern dalam format PNG dengan background transparan jika diperlukan
- Icon bisa diganti dengan emoji jika tidak tersedia file custom

## Upload File:
Silakan drag & drop file-file desain ke folder ini:
`public/assets/email/`
